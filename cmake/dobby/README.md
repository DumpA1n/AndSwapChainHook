# Dobby hook-only source package

`Dobby::Dobby` is an Android AArch64 static package built from official [jmpews/Dobby commit 5dfc8546954ce3b3198132ab13fddb89ee92cdd7](https://github.com/jmpews/Dobby/tree/5dfc8546954ce3b3198132ab13fddb89ee92cdd7), authored on 2024-03-14. The public source archive SHA-256 is `01a417233c40929aa21098c8a9724c00f6f05b5cde3f11abcac84b8e00053748`. Configuration requires the host `patch` utility, retrieves this exact archive without private credentials and verifies its digest. The local [ownership patch](ownership.patch), entry facade and permission writer form part of the source identity. [Apache-2.0](LICENSE) and upstream embedded attribution notices apply to upstream code. The package installs the license and patch.

The source list includes AArch64 relocation, normal trampolines and POSIX allocation. It excludes upstream build scripts, date-derived versions, constructor logging, near branches, plugins and instruction instrumentation. CMake uses target-scoped C++17, PIC, debug symbols, frame pointers and deterministic source path mapping; NDK hardening defaults remain enabled. There are no prebuilt archives or private source dependencies in this package. `DobbyBuildRevision()` reports the complete upstream revision and local contract version.

## Contract version 1

Only `DobbyHook`, `DobbyDestroy` and `DobbyBuildRevision` are public. The caller owns the target bytes, page permissions, mapping lifetime and external entry quiescence. Target mappings must be readable/executable. Executable-only mappings, PAC/BTI entry sequences, PC-relative literals, B.cond AL/NV, and branch/ADR targets within the overwritten instruction window are unsupported. The facade validates the actual 12/16-byte patch window before relocation; unsupported input returns `-ENOTSUP` without modifying target code or permissions. A single component instance serializes its operations; independent static copies and foreign code patchers do not share ownership.

Installation checks each bounded target range and saves exact page permissions before writing. The writer checks mapping identity and expected permissions on every operation, temporarily adds write permission, and restores each page's original flags. It returns negative errno values on permission, range, ownership and capacity failures. A partial failure retains the entry, original trampoline and permission record. A non-null `*original` on a failed `DobbyHook` means `DobbyDestroy` remains necessary. Failed restoration retains the record for retry. Foreign byte or permission changes cause `-EBUSY`; they are never overwritten as if owned. The embedding `HookTransaction` includes partially installed entries in rollback.

At most 256 installation attempts allocate entries/trampolines. Allocations remain resident until process exit, including failed preparation. The permission writer has 256 bounded records, each covering at most 17 pages and 65,536 bytes. Exhaustion returns `-ENOSPC`. Failed permission restoration can retain an executable allocator page and is not a safe-unload condition. No fallback changes dumpability, resolves private framework state or bypasses a denied permission request.

Restoration requires permanent retirement of all acquired replacement/original addresses. No such address may execute during restoration or become callable afterward. Parking threads is insufficient. This contract also applies to consumer-supplied implementations that may release trampolines. No API certifies DSO unloading, atomic instruction patching, concurrent foreign patchers, 16 KiB pages, MTE, BTI/PAC or ShadowCallStack.

## Consumption

Enabling `ANDSWAPCHAIN_BUILD_GRAPHICS` builds this package unless `Dobby::Dobby` already exists. An externally supplied target must expose `ANDSWAPCHAIN_DOBBY_CONTRACT_VERSION=1` and implement the documented partial-failure/ownership contract. Merely adding this property to an unmodified upstream binary does not satisfy the contract. The producer is responsible for matching source, API, artifact and symbols.

The package can be configured independently with `cmake -S cmake/dobby`, an Android AArch64 toolchain, and a Debug/Release build type. After installation, `find_package(Dobby 1 CONFIG REQUIRED)` imports `Dobby::Dobby`; its interface contains only installed paths. Installing AndSwapChainHook Graphics also installs the default Dobby package. No network retrieval occurs when consuming the installed packages.

The Android production fixture `andswapchain_dobby_test` uses link-time `mprotect` wrapping for write/restore failure injection, exact two-page permission restoration, foreign ownership checks, original calls and capacity exhaustion. `andswapchain_egl_test` patches owned presentation entries with exact EGL signatures and calls the real system EGL implementation. PLQ110 system exports start with PACIASP and are explicitly rejected; successful owned entry tests do not claim support for those system exports.
